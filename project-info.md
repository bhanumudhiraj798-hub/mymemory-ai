# MyMemory AI

A personal AI assistant that remembers what matters.

MyMemory AI uses Hindsight to provide long-term memory across conversations.

## Problem
AI assistants often lose context between conversations.

## Solution
MyMemory AI stores useful user context and retrieves relevant memories when needed.

## Technology
- Hindsight
- Python
- FastAPI
- React
- LLM API
